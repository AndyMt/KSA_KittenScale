# KSA_KittenScale
Scaled versions of KSA kitten heads and helmets (50 to 100%)

The python file is a very basic script which also contains some hard coded directories you would have to change (D:\Projects\KSA etc)

The blender file needs to have 3 collections:
- Expressions
- Animations
- Meshes

The release ZIP file contains directories for 50, 60, 70, 80 and 90%.
Copy the content of that directory to the Content\Core\Characters folder and overwrite the existing assets.
